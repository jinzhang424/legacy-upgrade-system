# Skill: behavior-baseline-capturer

Stage: repository_analysis
Objective: Capture baseline behavior that must be preserved during migration.

## Inputs
- Existing test evidence
- Logs, dashboards, and incident notes

## Steps
1. List critical user journeys and system contracts.
2. Capture expected outputs and non-functional thresholds.
3. Record ambiguous behavior requiring human decisions.

## Expected Output
- Baseline behavior checklist
- Ambiguity register with evidence links

## Human Escalation Triggers
- Baseline behavior is undocumented or disputed.
- Data correctness assumptions cannot be validated.
