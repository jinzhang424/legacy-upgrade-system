# Skill: migration-path-comparer

Stage: upgrade_planning
Objective: Compare viable migration paths using explicit tradeoff criteria.

## Inputs
- Analysis findings
- Business constraints and deadlines

## Steps
1. Define candidate paths and prerequisites.
2. Score each path on risk, effort, timeline, and maintainability.
3. Recommend primary and fallback paths.

## Expected Output
- Ranked migration options
- Decision rationale and fallback plan

## Human Escalation Triggers
- Top paths are close and require business prioritization.
- Delivery timeline conflicts with risk tolerance.
