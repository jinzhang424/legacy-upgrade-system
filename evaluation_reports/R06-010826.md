## Why this run failed where R3 to R5 did not

The analysis surfaced a quarter of the files R4 had found for the same dependency set, so the executor met the Express 5, Influx 5 and winston 3 call sites as out-of-plan surprises. The pipeline rule that an out-of-plan file requires a human decision, combined with a repair budget of 3 per command, turned three ordinary migration edits into three halts and an abandoned run. The bounded scope-expansion allowance introduced the next day (R7) is the direct response.

## Run-specific recommendations

- Analysis quality varies by a factor of four between runs on the same input (27 files here, 114 in R7 the next day); the analyzer needs a deterministic floor: every file that requires a bumped package is in scope.
- Startup logs should be written to the artifact directory from the start; here the executor's first attempts left log files inside the repository.
- A third consecutive out-of-plan halt on the same class of break (major-version API change) should escalate to "widen the plan for this dependency family" rather than "add one file".
