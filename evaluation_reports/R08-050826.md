## What the validator got right and wrong here

Right: the Playwright console check found the client bundle regression that three earlier runs had shipped unnoticed, and the repair was correct. Wrong: the same rule then rejected the run for a missing favicon, and the browser check loaded only the two root pages, so the search page, the admin sections and the Socket.IO handshake, all broken, were never exercised.

## Run-specific recommendations

- A 57-minute execution thread that ends in an interrupt should be detected earlier; the orchestrator polled repeatedly without a deadline.
- The scope-expansion budget of 3 was exhausted by Express 5 route files alone; the budget should scale with the number of framework major bumps.
- Console-error classification already existed (`out_of_scope`); the verdict should respect it rather than reject on classified noise.
- Vendored client replacements should be planned with their exact new filenames so they are not reported as unexpected files.
