# Skill: release-closure-curator

Stage: upgrade_execution
Objective: Close the upgrade with evidence, accountability, and follow-up tracking.

## Inputs
- Execution logs
- Monitoring and incident status

## Steps
1. Compile completion evidence for each plan phase.
2. Confirm operational readiness and on-call coverage.
3. Record residual debt and follow-up actions.

## Expected Output
- Release closure summary
- Post-upgrade action list

## Human Escalation Triggers
- Final acceptance criteria are unmet.
- Monitoring coverage is incomplete for changed components.
