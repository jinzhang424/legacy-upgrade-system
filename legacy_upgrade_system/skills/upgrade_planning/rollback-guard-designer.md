# Skill: rollback-guard-designer

Stage: upgrade_planning
Objective: Ensure rollback decisions are fast, objective, and testable.

## Inputs
- Plan phases and risk signals
- Monitoring and alerting setup

## Steps
1. Define rollback triggers per phase.
2. Specify safe rollback commands and data protections.
3. Validate rollback timing assumptions.

## Expected Output
- Rollback trigger matrix
- Recovery runbook checklist

## Human Escalation Triggers
- Rollback could cause data inconsistency.
- Recovery sequence is not operationally tested.
